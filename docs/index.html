Introduction

env-carry is a zero-setup, end-to-end encrypted CLI tool for transferring environment variables, auditing inherited codebases, detecting configuration drift, and executing applications without writing unencrypted secrets to disk.

It eliminates the dangerous practice of pasting plaintext .env files into Slack, Telegram, WhatsApp, or email threads during project takeovers and team handoffs.

Quick Run 
npx env-carry --help

Why env-carry

Developers usually share secrets insecurely because enterprise secrets managers (Doppler, Vault, 1Password) impose friction: mandatory accounts, paid seat pricing, team invite flows, and complex dashboard configurations.

During a rapid codebase takeover, contractor onboarding, or startup launch, developers default to the fastest path. env-carry offers the speed of a chat message with the security of AES-256-GCM encryption.

Security Model

All cryptographic operations use native Node.js crypto primitives with no external C-bindings or insecure dependencies.

  • Cipher: AES-256-GCM (Galois/Counter Mode)
  • Key Derivation: scrypt (N=16384, r=8, p=1) with 128-bit random salt
  • Integrity Tag: 128-bit authentication tag, aborts instantly on tampering
  • IV Nonce: 96-bit unique cryptographically secure random bytes
  • Transit Lifecycle: Single-use ephemeral relay with immediate burn-after-reading

Installation

env-carry can be executed directly via npx without installation, or installed globally for permanent terminal access.

Terminal 
# Global installation
npm install -g env-carry

# Or zero-install execution
npx env-carry --help

Core Concepts

4-Word Passphrases

When encrypting, env-carry generates an easy-to-read, high-entropy 4-word code such as amber-beacon-summit-oasis. You can speak this to a teammate or send it via a separate channel.

Carry Armor (carry://)

A single-line URL-safe string containing the complete encrypted envelope (salt, IV, tag, ciphertext). Because it is fully encrypted with AES-256-GCM, it is safe to paste anywhere.

Burn-After-Reading

When transferring over the ephemeral peer relay, the server serves the encrypted payload once and terminates immediately.

Workflow: Codebase Takeover

When taking over an existing repository, you must assume previous developers and contributors retain active credentials. env-carry automates credential identification, leak detection, and rotation.

01

Run the Takeover Audit

Scan your active environment file for known services and historical Git leaks.

Terminal 
env-carry audit .env
02

Review Classified Risk Levels

env-carry recognizes 30+ service credentials: Supabase admin keys, Stripe secret keys, Resend, OpenAI, AWS, GitHub PATs, databases, and JWT secrets. Each is assigned a severity rating (CRITICAL, HIGH, MEDIUM).

03

Check for Git History Leaks

The scanner uses git pickaxe log search to determine if any of your active secret values were ever committed to Git in the past. If found, they must be revoked immediately.

04

Execute the Rotation Checklist

The command outputs a ready-to-use TAKEOVER_CHECKLIST.md file with direct links to rotation settings in each provider dashboard.

Workflow: Ephemeral Peer Transfer

Transfer a .env file directly between two developers on the same local network or Wi-Fi without storing anything in cloud databases.

Sender

Run send on your machine. env-carry encrypts the file in RAM and opens a temporary relay.

env-carry send .env

Output gives you a 4-word passphrase and a temporary URL: http://192.168.1.15:52341/carry

Receiver

Run receive on the destination machine with the provided URL.

env-carry receive http://192.168.1.15:52341/carry

Input the passphrase when prompted. The file is decrypted, saved to .env, and the sender relay burns instantly.

Workflow: Chat-Safe Armor Codes

When developers are remote or async, use armor codes. The payload is encrypted with AES-256-GCM and formatted as a URL-safe string.

Sender creates armor string 
env-carry pack .env --armor

# Output:
# Passphrase: coral-beacon-pulse-summit
# carry://eyJ2ZXJzaW9uIjoxLCJhbGdvIjoiYWVzLTI1Ni1nY20i...

Paste the carry://... code in Slack, Discord, or email. Send the passphrase via a separate channel or direct message.

Receiver unpacks armor string 
env-carry unpack "carry://eyJ2ZXJzaW9uIjoxLCJ..." -p "coral-beacon-pulse-summit"

Workflow: Drift Detection

Prevent broken development builds caused by missing environment variables or stale template keys.

Check for drift 
env-carry check .env -e .env.example

The check inspects three conditions:

  • Missing Keys: Variables present in .env.example but omitted in your active .env.
  • Unconfigured Placeholders: Values still set to dummy defaults such as your_key_here, TODO, or xxx.
  • Empty Keys: Keys defined with empty values.

Workflow: Memory-Only Execution

Do not keep plaintext .env files lying on disk where rogue npm dependencies, scripts, or accidental git add . commands can capture them.

1. Seal the environment into git-trackable ciphertext 
env-carry seal .env
# Creates .env.carry. You can delete .env from disk.
2. Run your application directly 
env-carry run -f .env.carry -- npm run dev

env-carry decrypts the variables into RAM and injects them directly into the child process environment table. When the process finishes, the secrets disappear from memory.

Commands Reference

env-carry audit [file]

Audits environment variables, matches 30+ service patterns, and scans Git history for leaks.

Flag
Description
--checklist [path]
Exports Markdown checklist file (defaults to TAKEOVER_CHECKLIST.md)

env-carry send [file]

Encrypts a file in-memory and opens an ephemeral burn-after-reading HTTP relay.

Flag
Description
-p, --passphrase <phrase>
Custom passphrase (auto-generated if omitted)
--port <port>
Specific port for local relay server (defaults to random port)

env-carry receive <target>

Fetches from a relay URL or dearmors a carry:// string, decrypts with passphrase, and writes to disk.

Flag
Description
-p, --passphrase <phrase>
Decryption passphrase
-o, --output <path>
Target destination path (defaults to .env)

env-carry pack [file]

Encrypts .env into a .carry file or armor string.

Flag
Description
--armor
Prints copy-pasteable carry:// string to terminal instead of file
-o, --output <path>
Destination file (defaults to [file].carry)

env-carry unpack <source>

Decrypts a .carry file or carry:// string into .env format.

Flag
Description
--stdout
Prints decrypted variables directly to stdout without writing to disk
-o, --output <path>
Target output path (defaults to .env)

env-carry check [file]

Validates active .env against a template example file to catch drift.

Flag
Description
-e, --example <path>
Path to example file (defaults to auto-detecting .env.example)

env-carry run [command...]

Injects environment variables into child process memory without unencrypting on disk.

Flag
Description
-f, --file <path>
Source file: .env or .env.carry (defaults to .env)
-p, --passphrase <phrase>
Decryption passphrase if using an encrypted file

env-carry seal / unseal

Seals .env into encrypted .env.carry or unseals .env.carry back to .env.
